# Production — Noctambulle

La production est fournie par liens, sans recopier le projet :

- [Dépôt GitHub](https://github.com/setec-labs/hackaviz-2026)
- [Release 1.0.0](https://github.com/setec-labs/hackaviz-2026/releases/tag/1.0.0)
- [Guide d'installation et de lancement](https://setec-labs.github.io/hackaviz-2026/utilisateur/)
- [Captures et lecture de la carte](https://setec-labs.github.io/hackaviz-2026/utilisateur/carte/)

Après installation, lancer depuis la racine du projet :

```text
uv run python scripts/run_services.py
```

Ouvrir ensuite <http://localhost:5173>. L'application interactive nécessite les
services locaux ; le site GitHub Pages héberge uniquement la documentation.
